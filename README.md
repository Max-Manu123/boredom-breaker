# Boredom Breaker

**Turn free time into fun.**

A mobile-first activity discovery app for people who have free time and want a little inspiration.

## MVP
- Discover 24 activities across Games, Create, Move, Explore, Learn and Relax.
- Surprise Me random activity suggestion.
- Search and duration filters.
- Activity details with materials, simple steps and a Bori tip.
- Save favorites in localStorage.
- English and Portuguese interface toggle.
- Responsive desktop and mobile layouts.

## Stack
React, TypeScript, Vite and plain CSS. No backend or account required for this first version.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
